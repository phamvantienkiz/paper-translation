## 1. User Story Statement

**As a** Kỹ sư R&D / Độc giả nghiên cứu  
**I want to** Nhập liên kết bài báo (URL) hoặc mã định danh bài báo từ arXiv.org  
**So that** Hệ thống tự động tải tệp PDF gốc và trích xuất siêu dữ liệu (tiêu đề, tác giả, tóm tắt) mà không cần tải thủ công về máy  

---

## 2. Acceptance Criteria (Given-When-Then)

### AC1: [Happy Path — Tải tệp và trích xuất metadata arXiv thành công]
- **Given** Người dùng ở màn hình tiếp nhận bài báo và chọn tab "Nhập arXiv"
- **When** Người dùng dán liên kết hợp lệ (vd: `https://arxiv.org/abs/2310.12345` hoặc `https://arxiv.org/pdf/2310.12345.pdf`) hoặc mã ID hợp lệ (`2310.12345`) và bấm "Tiếp tục"
- **Then** Hệ thống chuẩn hóa ID arXiv, gọi arXiv API để tải về siêu dữ liệu (Title, Authors, Abstract) và tải tệp PDF tương ứng
- **And** Hiển thị thẻ tóm tắt thông tin bài báo (Preview Card) và chuyển trạng thái phiên sang `FETCHED`

### AC2: [Validation — Định dạng liên kết hoặc mã ID arXiv không hợp lệ]
- **Given** Người dùng nhập vào ô tìm kiếm arXiv
- **When** Chuỗi nhập vào không khớp biểu thức chính quy (Regex) của arXiv ID (vd: chuỗi chữ ngẫu nhiên, link web khác ngoài arXiv)
- **Then** Hệ thống không thực hiện gọi mạng ra ngoài
- **And** Hiển thị cảnh báo nội tuyến: "Định dạng liên kết hoặc mã arXiv không đúng. Vui lòng nhập định dạng chuẩn như `https://arxiv.org/abs/YYMM.NNNNN` hoặc `YYMM.NNNNN`."

### AC3: [Negative Path — Lỗi kết nối, Timeout hoặc bài báo không tồn tại (404)]
- **Given** Người dùng nhập một mã arXiv hợp lệ về mặt cú pháp nhưng bài báo không tồn tại trên arXiv hoặc mạng arXiv phản hồi timeout ($> 30$ giây)
- **When** Hệ thống gửi yêu cầu tải dữ liệu tới máy chủ arXiv
- **Then** Hệ thống ngắt kết nối an toàn, giải phóng tiến trình
- **And** Hiển thị thông báo lỗi: "Không thể kết nối hoặc không tìm thấy bài báo trên arXiv. Vui lòng kiểm tra lại mã bài báo hoặc tải lên tệp PDF trực tiếp."

## 3. Architecture Guardrails for Coding Agents (BẮT BUỘC ĐỌC TRƯỚC KHI CODE)

> ⛔ **Cảnh báo cho AI Coding Agent**: Trước khi sinh hoặc sửa code cho User Story này, Agent BẮT BUỘC phải tuân thủ các tài liệu kiến trúc sau:

1. **Security & Data Isolation** ([docs/architecture/07-security-architecture.md](file:///E:/MyProject/paper-translation/docs/architecture/07-security-architecture.md)):
   - Tuyệt đối chỉ cho phép tải tệp từ các domain được whitelist: `arxiv.org`, `export.arxiv.org`. Cấm để người dùng truyền URL tùy ý gây lỗ hổng SSRF (Server-Side Request Forgery).
2. **Integration & API Contract** ([docs/architecture/08-integration-architecture.md](file:///E:/MyProject/paper-translation/docs/architecture/08-integration-architecture.md)):
   - Thiết lập cấu hình HTTP client với Timeout tối đa là 30 giây và Retry tối đa 2 lần với Exponential Backoff.
   - Thêm User-Agent rõ ràng tuân thủ chính sách API của arXiv (arXiv API Guidelines).
3. **Design Principles** ([docs/architecture/09-design-principles.md](file:///E:/MyProject/paper-translation/docs/architecture/09-design-principles.md)):
   - Đóng gói toàn bộ logic gọi mạng ngoài vào `ArxivClient` tách biệt, triển khai Interface `PaperIngestionProvider`.
