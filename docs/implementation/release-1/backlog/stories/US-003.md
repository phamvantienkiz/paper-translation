# User Story: US-003 — Kết xuất ảnh nền trang gốc (Layer 0) & crop khối hình ảnh theo BBox qua PyMuPDF

**Mã Story**: US-003  
**Phiên bản**: 3.1  
**Ánh xạ PRD**: FR-03  
**Ưu tiên**: P0 (Must)  

---

## 1. Mô tả User Story (INVEST)
- **As a** Kỹ sư / Nhà nghiên cứu CNTT & AI
- **I want to** kết xuất ảnh chụp toàn trang PDF gốc ở độ phân giải cao (Layer 0) và crop riêng các khối hình vẽ (`figure`) bằng `PyMuPDF`
- **So that** mọi sơ đồ vector (TikZ/PGFPlots), đồ thị, đường kẻ bảng và hình minh họa được bảo toàn tuyệt đối 100% khi tái hiện trên HTML Canvas.

---

## 2. Acceptance Criteria (Given-When-Then)

### AC-01: Kết xuất ảnh nền toàn trang làm Layer 0 cho Canvas (Happy Path)
- **Given** tệp PDF bài báo gồm $N$ trang
- **When** `PageAssetService` xử lý từng trang qua `PyMuPDF (fitz)`
- **Then** mỗi trang được kết xuất thành tệp ảnh sắc nét `storage/pages/{session_id}/page_{n}.png` (200 DPI) và lưu thông số `width_pt`, `height_pt`, `page_image_path` vào bảng `paper_pages`.

### AC-02: Crop riêng các khối hình ảnh theo tọa độ chuẩn hóa (Happy Path)
- **Given** các khối bố cục có `label == 'figure'` (hoặc `picture`) với tọa độ chuẩn hóa `[x0, y0, x1, y1]`
- **When** quy đổi sang `fitz.Rect(x0 * width_pt, y0 * height_pt, x1 * width_pt, y1 * height_pt)`
- **Then** hệ thống crop hình ảnh ở độ phân giải cao và lưu vào `storage/figures/{session_id}/page_{n}_fig_{k}.png`.
