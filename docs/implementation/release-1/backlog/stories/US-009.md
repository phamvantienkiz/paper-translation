## 1. User Story Statement

**As a** Độc giả nghiên cứu khoa học  
**I want to** hệ thống điều phối thông minh giữa dịch vụ Standalone `llama.cpp` Server (`gemma-4-E2B-it-qat-UD-Q4_K_XL.gguf`) và Cloud Gemini (`gemini`), hiển thị rõ trạng thái động cơ trên giao diện và đồng bộ kết quả lên 3-Layer HTML Canvas Viewer  
**So that** tôi có thể theo dõi trực quan cấu hình phần cứng đang chạy (Gemma-4-E2B • 4 P-Cores • 16K/8K Ctx • $\le 8\text{GB}$ RAM) và đọc bản dịch tiếng Việt giữ nguyên bố cục 2 cột trên Canvas.  

---

## 2. Acceptance Criteria (Given-When-Then)

### AC1: [Happy Path — Điều phối Router sang Python Client của Standalone `llama.cpp` Server]
- **Given** cấu hình mặc định `LLM_PROVIDER="llama_cpp"`
- **When** `TranslationService.translate_paper(session_id)` được kích hoạt sau khi Indra OCR đã thu hồi sạch RAM
- **Then** router tự động điều phối yêu cầu sang `LlamaClientService` (giao tiếp qua mạng nội bộ với tiến trình `llama.cpp server` chạy model `gemma-4-E2B-it-qat-UD-Q4_K_XL.gguf`)
- **And** nếu cấu hình là `gemini`, router điều phối sang luồng gọi Single-Call đám mây.

### AC2: [Happy Path — Đồng bộ kết quả bản dịch vào SQLite `ocr_blocks` & `paper_segments`]
- **Given** Python Client hoàn thành toàn bộ các lô dịch 2,000–2,500 từ tiếng Anh và trả về từ điển `{block_id: translated_text}`
- **When** `TranslationService` lưu trữ kết quả
- **Then** toàn bộ bản ghi `ocr_blocks` và `paper_segments` tương ứng được cập nhật đầy đủ nội dung dịch tiếng Việt.

### AC3: [UI Transparency — Hiển thị huy hiệu `Gemma-4-E2B` & Thông số phần cứng trên Header]
- **Given** người dùng mở giao diện ứng dụng hoặc gọi `GET /api/v1/system/engine-status`
- **When** chế độ Local-First đang kích hoạt
- **Then** API trả về thông tin `model_name: "gemma-4-E2B-it-qat-UD-Q4_K_XL.gguf"`, `serving_mode: "standalone_server"`, `cpu_p_cores_threads: 4`, `hard_ram_ceiling_gb: 8.0`, `context_window: 16384`
- **And** Header giao diện người dùng hiển thị huy hiệu trực quan: 🟢 `Local LLM: Gemma-4-E2B (16K Ctx • 4 P-Cores • <=8GB RAM)`.

## 3. Architecture Guardrails for Coding Agents (BẮT BUỘC ĐỌC TRƯỚC KHI CODE)

> ⛔ **Cảnh báo cho AI Coding Agent**: Trước khi sinh hoặc sửa code cho User Story này, Agent BẮT BUỘC phải đọc và tuân thủ các tài liệu kiến trúc sau:

2. **Toàn Vẹn Dữ Liệu (`docs/architecture/05-data-architecture.md`)**:
   - Sử dụng SQLAlchemy Async Session đúng chuẩn, đảm bảo 100% tương thích với 3-Layer HTML Canvas Viewer.
