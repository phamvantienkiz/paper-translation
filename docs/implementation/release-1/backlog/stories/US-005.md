# User Story: US-005 — Tái hiện bài báo bản dịch trên 3-Layer HTML5 Canvas (Auto-Fit Text + KaTeX SVG)

**Mã Story**: US-005  
**Phiên bản**: 3.1  
**Ánh xạ PRD**: FR-05  
**Ưu tiên**: P0 (Must)  

---

## 1. Mô tả User Story (INVEST)
- **As a** Độc giả nghiên cứu CNTT & AI
- **I want to** xem bài báo bản dịch tiếng Việt trực tiếp trên giao diện HTML5 Canvas 3 lớp có bố cục 2 cột, hình ảnh và bảng biểu giống hệt bài báo gốc
- **So that** tôi có thể đọc bản dịch trực quan ngay trên bố cục chuẩn học thuật mà không bị mất sơ đồ vector hay lệch công thức toán.

---

## 2. Acceptance Criteria (Given-When-Then)

### AC-01: Kết xuất 3 lớp (Layer 0 Base Page + Layer 1 Whiteout + Layer 2 VI Text) trên Canvas (Happy Path)
- **Given** dữ liệu từ `GET /api/v1/sessions/{session_id}/canvas-data`
- **When** component `CanvasPaperViewer` hiển thị từng trang bài báo
- **Then** hệ thống vẽ ảnh nền trang gốc (`page_image_url`) lên Layer 0, vẽ hộp trắng (`#FFFFFF`) phủ đúng vùng `bbox_norm` của các khối `is_translatable = True` lên Layer 1, và vẽ văn bản tiếng Việt đã dịch lên Layer 2.

### AC-02: Tự động co giãn cỡ chữ vừa khít hộp (Binary-Search Font Auto-Scaling)
- **Given** văn bản dịch tiếng Việt dài hơn văn bản tiếng Anh gốc khoảng 15–20%
- **When** tính toán bố cục chữ trên Layer 2
- **Then** thuật toán tự động tìm cỡ chữ lớn nhất sao cho toàn bộ các dòng sau khi word-wrap nằm gọn trong chiều rộng và chiều cao của Bounding Box mà không tràn đè lên khối khác.

### AC-03: Hiển thị sắc nét công thức LaTeX inline và bảng biểu qua KaTeX SVG `foreignObject` (Edge Case)
- **Given** một khối văn bản dịch có chứa công thức toán học `$...$`, `$$...$$` hoặc bảng `<table>`
- **When** kết xuất khối đó lên Canvas
- **Then** hệ thống biên dịch công thức qua KaTeX và nhúng vào SVG `foreignObject` để vẽ lên Canvas với độ phân giải sắc nét, tuyệt đối không in ra chuỗi ký tự `$` thô.
