## 2. Acceptance Criteria (Given-When-Then)

### AC1: [Happy Path — Dịch thuật phân đoạn thành công bảo toàn token toán học và glossary]
- **Given** Phân đoạn văn bản đã được cô lập công thức toán thành các token bảo vệ (vd: `<<<MATH_TOKEN_001>>>`) và bộ Glossary đã nạp
- **When** Pipeline dịch thuật gửi phân đoạn kèm chỉ dẫn Glossary tới AI Translation Engine
- **Then** Bản dịch tiếng Việt được trả về với văn phong học thuật mạch lạc
- **And** Toàn bộ các token bảo vệ `<<<MATH_TOKEN_NNN>>>` được giữ nguyên vẹn 100% vị trí trong câu dịch
- **And** Hệ thống tái nạp lại đúng chuỗi LaTeX gốc từ bảng Math Table vào bản dịch tiếng Việt

### AC2: [Edge Case — Bảo toàn các đoạn mã nguồn (Code Blocks) và ký hiệu tên biến]
- **Given** Phân đoạn bài báo có chứa các đoạn mã nguồn (pseudocode, block code ```` ``` ````) hoặc các biến số đơn lẻ (vd: `W`, `b`, `x_i`)
- **When** Bộ máy dịch AI thực hiện dịch phân đoạn
- **Then** Toàn bộ nội dung bên trong code block và tên các biến số không bị dịch sang tiếng Việt
- **And** Giữ nguyên cú pháp định dạng monospace và thụt lề ban đầu

### AC3: [Negative Path — Xử lý lỗi timeout hoặc bị giới hạn tốc độ (Rate Limit / 429) từ AI Engine]
- **Given** Yêu cầu dịch một phân đoạn gặp sự cố từ AI Provider (timeout $> 45$ giây hoặc phản hồi mã HTTP 429 Too Many Requests)
- **When** Pipeline phát hiện lỗi gọi mạng
- **Then** Hệ thống kích hoạt cơ chế tự động thử lại (Retry) tối đa 3 lần với thời gian chờ tăng dần (Exponential Backoff)
- **And** Nếu sau 3 lần vẫn thất bại, hệ thống đánh dấu trạng thái phân đoạn là `TRANSLATION_FAILED`, không làm sập toàn bộ phiên đọc, và hiển thị nút "Thử dịch lại đoạn này" cho người dùng

## 3. Architecture Guardrails for Coding Agents (BẮT BUỘC ĐỌC TRƯỚC KHI CODE)

> ⛔ **Cảnh báo cho AI Coding Agent**: Trước khi sinh hoặc sửa code cho User Story này, Agent BẮT BUỘC phải tuân thủ các tài liệu kiến trúc sau:

1. **Data Model Guardrails** ([docs/architecture/05-data-architecture.md](file:///E:/MyProject/paper-translation/docs/architecture/05-data-architecture.md)):
   - Cập nhật bảng `PaperSegment`: điền `translated_content`, `translation_status` (`PENDING`, `IN_PROGRESS`, `COMPLETED`, `FAILED`).
   - Cấm ghi đè hoặc làm thay đổi trường `original_content` của phân đoạn.
2. **Security & Secrets Guardrails** ([docs/architecture/07-security-architecture.md](file:///E:/MyProject/paper-translation/docs/architecture/07-security-architecture.md)):
   - Tuyệt đối nạp API Key của AI Engine qua biến môi trường phía backend (`os.getenv("AI_API_KEY")`), cấm hardcode vào mã nguồn hoặc lộ ra API response.
3. **Integration & Resilience** ([docs/architecture/08-integration-architecture.md](file:///E:/MyProject/paper-translation/docs/architecture/08-integration-architecture.md)):
   - Bắt buộc bọc lệnh gọi AI Engine bằng Circuit Breaker hoặc Retry Handler có giới hạn.
4. **Design Principles** ([docs/architecture/09-design-principles.md](file:///E:/MyProject/paper-translation/docs/architecture/09-design-principles.md)):
   - Sử dụng mô hình xử lý bất đồng bộ (Async/Await) theo hàng đợi hoặc batch để tránh nghẽn thread chính của server khi bài báo có nhiều trang.
